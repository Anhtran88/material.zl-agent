Zalo Local Agent

Kết nối trình duyệt trên máy bạn với công cụ hỗ trợ MCP. Phiên chat cần cấu hình MCP riêng để sử dụng cầu nối.

Trình duyệt Zalo

Đóng trình duyệt Agent cũ trước khi mở. Đăng nhập và chọn nhóm ĐỐI CHIẾU KL- KẾ TOÁN IJC thủ công.

Chưa kết nối

Kết nối đọc có hiệu lực 30 phút. Khi nhóm/UI thay đổi hoặc có hộp thoại, Agent dừng để bạn kiểm tra.

Báo cáo được lưu trực tiếp lên Firestore materialzlagent. Kiểm tra cloudStorage.saved trong kết quả; lỗi lưu sẽ dừng đọc. Không tự lưu báo cáo trên máy. Dữ liệu RAW chưa xác minh; chưa đầy đủ người gửi/thời gian, file và lịch sử. Chưa tải ảnh gốc, chưa xử lý giao nhận hay cập nhật checkpoint.

9Router

Cấu hình cục bộ. Kiểm tra /models không gửi dữ liệu Zalo sang AI.

API key của ứng dụng được mã hóa bằng Windows DPAPI. 9Router quản lý thông tin provider theo cơ chế riêng. Chưa có luồng gửi chat/OCR sang AI.

Cầu nối MCP

Chỉ dùng với ứng dụng MCP trên cùng máy Windows. Cài Local Agent chưa tự kết nối phiên chat cloud.
